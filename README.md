## Зачем LifeOS

Когда работаешь сразу над несколькими проектами, ручной хронометраж отвлекает от дела. LifeOS считает активность за компьютером, помогает распределять её по проектам и напоминает делать перерывы. **Неизвестное время остаётся неизвестным:** программа не выдаёт догадки за подтверждённый учёт.

## Что работает

| Возможность | Поведение |
| --- | --- |
| Активное время | Считается по активному приложению Windows; простой и сон не приравниваются к работе. |
| Проекты и задачи | Локальный каталог, подтверждённые привязки к рабочему контексту; нераспознанное время можно разбирать вручную. |
| Перерывы | Настраиваемые интервалы, напоминания, пауза и возобновление. |
| Обзор дня | Статистика по времени и распределению между известными проектами. |
| Браузер | Дополнительное расширение может отправлять в локальную LifeOS ограниченный контекст активной вкладки — только после подключения. |
| Обновления | Проверка подписанных выпусков, запрос согласия перед установкой, хранение предыдущей версии для отката. |

**Ограничения preview:** поддержка браузерного расширения и автоматическая привязка произвольных чатов пока не завершены; реальные проверки в разных браузерах продолжаются. LifeOS не читает тексты Telegram/Mattermost, не выполняет семантическое суммирование чатов и не обещает безошибочное определение любой задачи.

## Скачать и начать работу

1. Открой [раздел Releases](https://github.com/valmasone/LifeOS-releases/releases) и выбери нужный предварительный Windows-выпуск. Текущая опубликованная версия канала — **0.4.9 preview**; работа над следующим выпуском идёт в приватном репозитории.
2. Для опубликованного ZIP распакуй **весь** архив в отдельную папку. Запусти `LifeOS.exe` на Windows. Если позже доступен проверенный установщик LifeOS Setup, он предпочтительнее для установки с постоянным Launcher и OTA.
3. Настрой продолжительность работы и отдыха. При необходимости разреши локальное распознавание рабочих пространств.
4. Подключение браузера необязательно. Если не установлен проверенный магазинный вариант расширения, не ожидай автоматической установки стороннего CRX без участия браузера.

[Подробная установка, обновление и сохранность данных](INSTALL.md).

## Приватность — по умолчанию локально

История активности и список проектов находятся в профиле Windows пользователя. LifeOS **не отправляет рабочую историю на наши серверы**. Браузерное расширение не передаёт содержимое страниц, тексты переписок, историю просмотра или полные URL в облако. По согласию пользователя оно может локально передавать домен, идентификатор репозитория/задачи/канала/беседы и название группы вкладок. Эти признаки тоже могут быть конфиденциальными; доступ ограничен локальным мостом.

Интернет используется для загрузки подписанных метаданных/файлов обновлений. При сетевых запросах провайдер может видеть IP-адрес. Локальная SQLite не зашифрована самим приложением: безопасность также зависит от Windows и шифрования диска.

## Состояние проекта

| Платформа | Состояние |
| --- | --- |
| **Windows x64** | Preview — доступно для тестирования |
| **Браузерное расширение** | Подготовка к Opera Add-ons; магазинное распространение ещё не подтверждено |
| Android | Отложено до Windows 1.0 |
| Синхронизация устройств | Ещё не реализована |

**Это не стабильная Windows 1.0.** Часть проверок безопасности, доступности интерфейса, браузерной совместимости и длительной работы ещё открыта. [Что изменилось](CHANGELOG.md) · [Известные ограничения и поддержка](SUPPORT.md).
