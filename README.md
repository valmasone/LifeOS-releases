## Почему появился LifeOS

Когда одновременно ведёшь больше трёх проектов, становится трудно помнить, над чем и сколько работал, следить за перерывами, движением и собственным здоровьем. Постоянный ручной учёт превращается в ещё одну задачу. LifeOS создан, чтобы снять часть этой нагрузки: автоматически учитывать время, помогать распределять его по проектам и вовремя напоминать об отдыхе.

## Больше ясности. Меньше ручной работы.

LifeOS создан для тех, кто проводит много времени за компьютером, работает над несколькими проектами и хочет успевать не только выполнять задачи, но и отдыхать.

### Возможности

| | |
| :--- | :--- |
| **Время под контролем** | Учёт активности за компьютером с учётом перерывов и отсутствия. |
| **Проекты и задачи** | Определение рабочего контекста в поддерживаемых приложениях и браузерах с разрешения пользователя. |
| **Перерывы вовремя** | Настраиваемые напоминания, отдых и возвращение к работе в комфортном ритме. |
| **Понятная статистика** | Сколько времени прошло за компьютером и на что оно было потрачено. |
| **Личная приватность** | Рабочая история по умолчанию хранится на устройстве. |

LifeOS не заставляет заполнять каждый рабочий интервал вручную. Когда точного контекста недостаточно, время остаётся нераспределённым, а не приписывается случайному проекту.

## Как пользоваться

**1.** Скачай доступную версию LifeOS в [Releases](https://github.com/valmasone/LifeOS-releases/releases).

**2.** Распакуй архив целиком и запусти `LifeOS.exe` на Windows.

**3.** Выбери удобный ритм работы и отдыха. Учёт активности начнётся автоматически.

**4.** При желании подключи браузер, чтобы LifeOS точнее определял проекты. Первое подключение требует разрешения в браузере.

Для обычного учёта времени и напоминаний о перерывах не нужно заранее создавать список задач.

## Данные и приватность

**История работы хранится на твоём компьютере.** В текущей Windows-версии LifeOS локально сохраняет время активности, проекты, задачи и статистику. Эти данные не отправляются на серверы LifeOS и не используются для удалённого отслеживания пользователей.

Распознавание рабочего контекста браузера включается только с разрешения пользователя. Расширение взаимодействует с локальным компонентом LifeOS, не передавая содержимое страниц, переписки, историю посещений и нажатия клавиш в облако.

**Интернет может использоваться для проверки и скачивания обновлений**, но рабочая история при этом не передаётся. Как при любом сетевом запросе, сервису доставки может быть виден IP-адрес устройства. Планируемые облачные функции потребуют отдельного согласия пользователя.
