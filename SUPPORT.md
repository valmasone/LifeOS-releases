# LifeOS — поддержка и известные ограничения

[На главную](README.md) · [Выпуски](https://github.com/valmasone/LifeOS-releases/releases) · [Сообщить о проблеме](https://github.com/valmasone/LifeOS-releases/issues/new)

## Что сообщить об ошибке

Укажи версию LifeOS, версию Windows, название браузера, точные шаги воспроизведения и ожидаемый/фактический результат. Скриншоты можно прикладывать только после удаления адресов, имён частных проектов и личной информации. **Не публикуй** токены, тексты рабочих переписок, личные SQLite базы, приватные URL или закрытые ключи.

## Нет связи с браузерным расширением

Убедись, что расширение действительно включено в браузере и установлена Windows LifeOS. Проверь всплывающее окно расширения, страницу расширений и включение браузерного распознавания в LifeOS. Иногда помогает обновление активной вкладки после установки расширения. Локальный Native Messaging мост должен разрешать конкретный ID расширения — ID из магазина может отличаться от ID локального CRX.

В браузерах могут действовать ограничения на установку сторонних расширений. Мы не рекомендуем обход политик безопасности или отключение защиты.

## Часы считаются, а проект не найден

Это допустимо, когда нет однозначных признаков. Домен `chatgpt.com` или процесс `Telegram.exe` сам по себе не идентифицирует конкретный проект. В текущей preview система может распознать поддерживаемую рабочую папку, репозиторий, тикет или предварительно подтверждённую связь с чатом/вкладкой. Неизвестные интервалы сохраняются отдельно. Полное смысловое чтение переписок в выпущенной версии отсутствует.

## Сохранится ли история при обновлении?

При управляемой установке SQLite и настройки находятся вне каталога версий, предыдущий EXE сохраняется для отката. При ручном переносе портативных папок сначала экспортируй важную историю. Резервная копия пользователя — дополнительная защита от ошибок диска и системы.

## Лимиты и несовместимость

- Пока поддерживается только Windows x64; Android и синхронизация между устройствами отложены.
- Автоматическая привязка чатов не гарантирует точность на всех сайтах и приложениях.
- Браузерный мост не подтверждён для каждого сочетания версий Opera / Яндекс / Chrome.
- Полный аудит безопасности, Authenticode и длительная приёмка Windows 1.0 ещё не завершены.
