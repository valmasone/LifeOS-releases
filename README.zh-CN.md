## LifeOS 的由来

同时处理三个以上的项目时，很难记住时间花在哪里，也不容易兼顾休息、运动和健康。手工填写工时往往又成了一项负担。LifeOS 希望通过自动记录活动、帮助分配项目时间和适时提醒休息，让这件事变得轻松一些。

## 更清楚地了解时间，减少手动记录

LifeOS 面向需要长时间使用电脑、同时处理多个项目，并希望在工作之外拥有更多个人时间的用户。

### 主要功能

| | |
| :--- | :--- |
| **活动时间统计** | 记录电脑活跃时间，并区分休息和离开电脑的时段。 |
| **项目与任务** | 经用户授权后，从受支持的应用程序和浏览器识别工作项目。 |
| **定时休息提醒** | 自定义工作与休息周期，帮助建立更舒适的节奏。 |
| **每日统计** | 直观查看电脑活动时长和项目时间分配。 |
| **重视隐私** | 工作记录默认保存在本机。 |

LifeOS 尽量减少手动填写。对于无法准确识别的项目，系统会保留未分类时间，而不会随意分配。

## 如何使用

**1.** 从 [Releases](https://github.com/valmasone/LifeOS-releases/releases) 下载可用版本。

**2.** 完整解压安装包，在 Windows 上运行 `LifeOS.exe`。

**3.** 调整工作和休息时间，程序会自动开始记录活动。

**4.** 如有需要，可授权连接浏览器，以改善项目识别效果。首次连接需要浏览器授权。

使用时间统计和休息提醒功能，无须提前手动建立所有任务。

## 隐私保护

**工作时间、项目和任务记录默认只保存在用户自己的电脑中，不会上传到 LifeOS 服务器。** 浏览器项目识别须由用户自行授权，信息仅在本机处理。软件可以联网检查或下载更新，但不会因此上传工作记录；更新服务可能看到普通网络请求所包含的设备 IP 地址。未来的云端功能需要单独获得用户同意。
