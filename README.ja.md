## LifeOS が生まれた理由

3つ以上のプロジェクトを同時に進めると、時間の使い道が分かりにくくなり、休憩や運動、健康管理まで気を配るのが難しくなります。手入力での時間記録も新たな負担になります。LifeOS は活動時間の自動記録と休憩のリマインダーで、その負担を減らすために生まれました。

## 主な機能

- **活動時間の記録** — PCでの活動と検出された離席時間を区別します。
- **プロジェクトとタスク** — 許可を得て作業状況から時間の割り当てを補助します。
- **休憩リマインダー** — 作業と休憩の間隔を調整できます。
- **1日の振り返り** — 時間の使い方を確認できます。
- **プライバシー** — 作業履歴は原則として端末内に保存されます。

## 使い始めるには

1. [Releases](https://github.com/valmasone/LifeOS-releases/releases) から利用可能なバージョンをダウンロードします。
2. ZIPをすべて展開し、Windowsで `LifeOS.exe` を起動します。
3. 作業と休憩の時間を設定すると、記録が自動的に始まります。
4. 必要に応じてブラウザー連携を許可してください。

> **プレビュー版:** Releasesのファイルはテスト用です。Androidアプリとデバイス間同期は今後の予定です。

## データとプライバシー

作業履歴はご自身のPCに保存され、LifeOSサーバーへアップロードされません。ブラウザー連携は任意です。更新の確認やダウンロードでは、配信サービスにIPアドレスなど通常の通信情報が見える場合がありますが、作業履歴は送信されません。
