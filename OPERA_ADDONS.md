# LifeOS Projects — Opera Add-ons

[LifeOS](README.md) · [Конфиденциальность](PRIVACY.md) · [Поддержка](SUPPORT.md)

LifeOS Projects — необязательное расширение браузера для распознавания рабочего контекста **активной вкладки** и передачи ограниченных признаков в локальное Windows-приложение LifeOS через Native Messaging. Оно **не** является самостоятельным трекером и не заменяет LifeOS для Windows.

## Данные карточки для Opera

**Название:** LifeOS — рабочие проекты

**Категория:** Productivity

**Краткое описание:**

> LifeOS Projects помогает локальной LifeOS распознавать рабочий контекст активной вкладки и относить время к проектам.

**Полное описание:**

> LifeOS Projects работает вместе с установленным приложением LifeOS для Windows. Когда пользователь включает распознавание, расширение передаёт через локальный Native Messaging мост ограниченные сведения об активной вкладке. Приложение может сопоставлять рабочее время с известными проектами по репозиториям GitHub/GitLab, ключам задач Jira, поддерживаемым идентификаторам рабочих каналов и подтверждённым связям вкладок. Неоднозначное время остаётся нераспределённым.
>
> Во всплывающем окне расширения можно включить или отключить распознавание, проверить состояние соединения и увидеть последний распознанный контекст.
>
> Расширение не читает тексты страниц, переписок, cookie и пароли, не использует историю посещений и не отправляет сведения о работе стороннему облачному ИИ. Данные передаются только установленному локальному приложению. Для работы требуется Windows LifeOS и зарегистрированный Native Messaging мост. Предварительная версия: не все браузеры и сайты прошли реальную приёмку.

## Зачем нужны разрешения

| Разрешение | Применение |
| --- | --- |
| `tabs` | Получение URL именно активной вкладки, только в памяти для выделения структурированного признака. Разрешение `history` не запрашивается. |
| `tabGroups` | Название группы активной вкладки для подтверждённой привязки к проекту. |
| `nativeMessaging` | Связь с установленным локально LifeOSBrowserBridge.exe. |
| `storage` | Локальное включение/отключение распознавания и статус подключения. |
| `alarms` | Периодическая актуализация статуса текущей вкладки. |

Нет `content_scripts`, `host_permissions`, кода удалённого сервера или доступа к старой истории посещений.

## Подготовка к модерации

1. На странице разработчика Opera нажать "Upload new add-on" → "Select files"; загрузить **только** `LifeOS-Projects-Opera-0.4.10-Store.zip`, не ZIP Windows и не комплект документации. В пакете нет приватных ключей.
2. Проверить, что Opera распознала название и версию. Заполнить карточку содержательной информацией выше.
3. Добавить два **реальных**, а не синтетических скриншота: popup расширения в браузере и панель с показанным состоянием подключения. По официальному руководству предпочтительно 612×408 px, белый фон, не больше 800×600 px.
4. До отправки проверить тестовую установку в Opera и Яндекс Браузере (если поддерживается) и пользовательское согласие. Внимание: текущая опубликованная Windows LifeOS 0.4.9 ещё **не доверяет ID нового магазинного расширения**. Для реальной работы нужно сначала получить Opera extension ID и включить его в следующий проверенный, подписанный Windows-выпуск.
5. Окончательный "Submit for Review" только после согласия владельца и проверки карточки.

После появления в кабинете **настоящего ID или URL карточки** передать его разработке LifeOS; в подписываемом клиенте заполняются два поля `store_ids.json` и `store_listing.json`. Только затем связка browser → native host может быть реально подтверждена на устройстве.

**Ограничения:** расширение не даёт доступа к произвольным перепискам Telegram Desktop/Mattermost Desktop и не умеет смысловую суммаризацию сообщений. Не обещать такие функции в магазине.

Официальные критерии Opera: https://help.opera.com/en/extensions/publishing-guidelines/
