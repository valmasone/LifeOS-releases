## LifeOS를 만든 이유

세 개가 넘는 프로젝트를 동시에 진행하면 어디에 시간을 썼는지 파악하고 휴식, 운동, 건강까지 챙기기 어렵습니다. 매번 시간을 수동으로 기록하는 것 또한 새로운 업무가 됩니다. LifeOS는 자동 활동 기록과 적절한 휴식 알림으로 이런 부담을 줄이기 위해 시작되었습니다.

## 주요 기능

- **활동 시간** — 컴퓨터 사용 시간과 감지된 휴식 시간을 구분합니다.
- **프로젝트 및 작업** — 동의를 받아 업무 맥락에 맞게 시간을 분류합니다.
- **휴식 알림** — 개인에게 맞는 작업 및 휴식 간격을 설정합니다.
- **하루 요약** — 시간을 어디에 사용했는지 확인합니다.
- **개인정보 보호** — 작업 기록은 기본적으로 내 컴퓨터에 저장됩니다.

## 시작하기

1. [Releases](https://github.com/valmasone/LifeOS-releases/releases)에서 사용 가능한 버전을 다운로드하세요.
2. ZIP을 모두 압축 해제하고 Windows에서 `LifeOS.exe`를 실행하세요.
3. 작업 및 휴식 간격을 설정하면 활동 기록이 자동으로 시작됩니다.
4. 원하는 경우 브라우저 확장 프로그램 연결을 허용하세요.

> **미리 보기 버전:** Releases 파일은 테스트용입니다. Android 및 기기 간 동기화는 아직 개발 중입니다.

## 데이터와 개인정보

작업 기록은 사용자의 컴퓨터에 저장되며 LifeOS 서버로 업로드되지 않습니다. 브라우저 연결은 선택 사항이며 동의가 필요합니다. 업데이트 확인 및 다운로드에서는 일반 네트워크 정보(IP 주소 등)가 배포 서비스에 보일 수 있지만 작업 기록은 전송되지 않습니다.
