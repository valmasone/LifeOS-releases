# LifeOS — история публичных выпусков

[Скачать](https://github.com/valmasone/LifeOS-releases/releases) · [На главную](README.md)

## 0.4.9 — Windows Preview (20 октября 2026)

- Подготовлено распознавание контекста в поддерживаемых рабочих редакторах и браузерных вкладках, с возможностью сохранять явные связи между контекстом и проектом.
- Улучшено отображение статуса "Без проекта" и объяснение причин отсутствия достоверной атрибуции.
- Добавлена ежедневная сводка по фактически учтённым интервалам; неизвестные задачи не придумываются.
- Изменён сценарий установки локального расширения в Яндекс Браузере после выявленной проблемы с перетаскиванием Qt. Для локального CRX3 всё ещё может потребоваться ручной шаг.
- Windows сборка и установщик проверены в GitHub Actions, но это не означает прохождения всех реальных пользовательских сценариев.

Известное ограничение: шаблонное описание в уведомлении релиза не отражало все изменения. Исправление подготовки будущих release notes находится в разработке.

## 0.4.8 — Windows Preview (20 октября 2026)

- Подписанный пакет Windows и механизм локального издателя.
- Реальная установка по OTA с 0.4.6 на тестовом устройстве подтверждена владельцем.
- Подготовка CRX3 с локально защищённым ключом подписи; первая реализация перетаскивания не прошла пользовательский тест.

## Следующая версия

Windows-кандидат **0.4.10** проверялся в CI, но не опубликован в канале OTA. Управление проектами, уточнение нераспознанного времени и подготовка магазинного браузерного расширения пока проходят дальнейшие проверки.

Этот файл описывает подтверждённые публичные выпуски и известные ограничения. Коммит в приватной ветке разработки сам по себе не является опубликованным релизом.
