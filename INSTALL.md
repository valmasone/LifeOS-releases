# Установка и обновления LifeOS для Windows

[На главную](README.md) · [Загрузки](https://github.com/valmasone/LifeOS-releases/releases)

## Первый запуск

Доступный публично Windows Preview распространяется в виде ZIP-архива в GitHub Releases. Выбирай **архив именно нужной версии**, скачай, распакуй **весь** архив в одну отдельную папку и запусти `LifeOS.exe`. Не запускай EXE прямо из архива и не удаляй вложенные библиотеки.

Поддерживаемая ОС текущего проекта — Windows x64. Программа предназначена для персонального учёта времени и не является медицинским устройством.

Если для конкретного выпуска дополнительно опубликован проверенный стандартный установщик `LifeOSSetup`, лучше установить его: он создаёт стабильный `LifeOSLauncher.exe` и разделяет версии для OTA. Публичные ZIP-файлы не следует автоматически считать полноценными установщиками с гарантированным OTA.

## Где хранятся файлы

| Папка | Содержимое |
| --- | --- |
| `%LOCALAPPDATA%\LifeOS` | История, настройки, проекты, SQLite и бэкапы |
| `%LOCALAPPDATA%\LifeOS\updates\cache` | Временные скачанные ZIP для OTA |
| `%LOCALAPPDATA%\Programs\LifeOS\versions` | Версии управляемой установки, если она используется |

После успешного управляемого обновления LifeOS пытается удалить скачанный ZIP. Фоновая очистка оставшихся служебных файлов работает по возрасту. Предыдущую установленную версию сохраняем для отката; **файлы SQLite и резервных копий не удаляются вместе с кешем**.

## Обновления

В установленной LifeOS: "Настройки" → "Проверить обновления". Клиент проверяет подпись Ed25519 и SHA-256 скачиваемого пакета. Установка начинается только после выбора пользователя. При ошибке установщик должен сохранить предыдущую работоспособную версию и историю; автоматический откат на любом оборудовании ещё проходит тестирование.

Возможны предупреждения Windows SmartScreen для новых бинарников без широко признанной подписи Authenticode. Не отключай защиту Windows ради установки; при сомнениях дождись стабильного релиза.

## Браузерное расширение

Расширение пока находится на этапе подготовки к каталогу Opera Add-ons. Яндекс Браузер умеет устанавливать расширения из Opera Add-ons, если браузер считает их совместимыми. Старое локальное расширение CRX3 может требовать ручного перетаскивания в `browser://tune`; магазинное расширение после публикации будет иметь другой ID и потребует, чтобы версия Windows LifeOS разрешала этот ID в локальном мосте.

При проблемах с подключением см. [поддержку](SUPPORT.md).

## Удаление

Перед удалением экспортируй историю, если она нужна. Установщик управляемой версии не должен стирать `%LOCALAPPDATA%\LifeOS`; ручное удаление этой папки удалит пользовательские данные и резервные копии. Не смешивай несколько распакованных версий в одной папке.
